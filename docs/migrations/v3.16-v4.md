
## Nuxt v3.16 迁移至 v4.0.0 指南

`Nuxt-3.16.0` 升级至 `Nuxt-4.0.3`。

1. `router.options.ts` 目录变更：由原来的 `~/app/router.options.ts` 变更至 `~/router.options.ts`。
2. 默认的 `srcDir` 变更：

- `public` 及 `server` 目录需手动配置为：

```ts
// nuxt.config.ts

export default defineNuxtConfig({
  // ...

  dir: {
    public: 'src/public/',
  },

  // ...

  serverDir: 'src/server/',
})
```

3. `sass` 默认使用现代api。
4. 内联styles现在需要手动配置为: `true`。

```ts
export default defineNuxtConfig({
  features: {
    inlineStyles: true,
  },
})
```
